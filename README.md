# Denkwerk

Ein ChatGPT-ähnlicher KI-Chat für Android-Tablets und -Handys.

- **Auf dem Gerät:** Gemma 4 E2B/E4B über LiteRT-LM (offline, Grafikchip), eigene `.litertlm`-Dateien
- **Ollama im Netzwerk:** alle Modelle vom PC, mit automatischer Bild-Erkennung (Vision)
- Markdown, Code-Blöcke mit Kopieren, Bilder anhängen, Spracheingabe, Vorlesen
- Chat-Verlauf mit Suche, Anheften, Umbenennen

## APK

Jeder Push auf `main` baut automatisch eine neue APK:
